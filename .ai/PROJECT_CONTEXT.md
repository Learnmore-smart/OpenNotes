## NEVER Change
1. **剥离式注释加载架构**（不直接渲染 PDF 注释层）：加载时 `ExtractAndStripAnnotations` 把 /Ink /FreeText /Highlight 抽出并从 /Annots 移除，PdfiumViewer 渲染的是剥离后的流；应用内自绘。
2. **坐标系**：注释 DIP 96dpi；保存时 `scale = 72/96` 且 Y 翻转（`pageHeight - y`）。加载时反向 `scale = 96/72`。
3. **保存走临时文件 + `File.Move(tempPath, filePath, true)` 原子替换**（SaveAnnotationsCore 行 1096-1099），失败提示文件被占用。
4. **undo 为 IUndoAction 命令栈**（页面增删等结构性操作用 `DocumentSnapshotAction` 字节快照，`LeavesDocumentDirty=false`）。
5. **单窗口 Frame 标签架构**（MainWindow `List<AppTab> _tabs` + Frame.Navigate）。
