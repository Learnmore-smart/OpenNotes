## 项目概览
WPF (.NET 8) PDF 笔记应用，正式产品和工作区名称为 **OpenNotes**；`Caelum` 仅作为旧命名空间、历史数据目录和安装兼容标识保留，避免破坏已有用户数据。正式 checkout 已位于 `D:\Noah\文档\Coding\1. Open-Source\OpenNotes`；旧 `D:\Noah\文档\Coding\2. 开源的项目\Caelum` 仅作为历史路径保留。单 MainWindow + Frame 标签页导航（`MainWindow.xaml.cs` 中 `List<AppTab> _tabs`）。每个标签一个 EditorPage，PDF 页面以 `PdfPageControl` 直接堆叠于 `PagesContainer` StackPanel（**非虚拟化**）。PdfiumViewer 渲染 + PdfSharpCore 注释读写（/Ink /FreeText /Highlight **剥离式加载**：`ExtractAndStripAnnotations` 抽出注释后自绘于 InkCanvas/TextOverlayCanvas/HighlightsCanvas，PdfiumViewer 只看到无注释的“干净”PDF 流）。

## NEVER Change
1. **剥离式注释加载架构**（不直接渲染 PDF 注释层）：加载时 `ExtractAndStripAnnotations` 把 /Ink /FreeText /Highlight 抽出并从 /Annots 移除，PdfiumViewer 渲染的是剥离后的流；应用内自绘。
2. **坐标系**：注释 DIP 96dpi；保存时 `scale = 72/96` 且 Y 翻转（`pageHeight - y`）。加载时反向 `scale = 96/72`。
3. **保存走临时文件 + `File.Move(tempPath, filePath, true)` 原子替换**（SaveAnnotationsCore 行 1096-1099），失败提示文件被占用。
4. **undo 为 IUndoAction 命令栈**（页面增删等结构性操作用 `DocumentSnapshotAction` 字节快照，`LeavesDocumentDirty=false`）。
5. **单窗口 Frame 标签架构**（MainWindow `List<AppTab> _tabs` + Frame.Navigate）。
